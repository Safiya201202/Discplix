# DISCPLIX

A single-page productivity app: tasks, habits, focus timer, calendar, goals and analytics.
Pure HTML/CSS/JS, no build step.

## Deploy on Vercel
1. Put these files at the **root** of your GitHub repo (`index.html` must be at the top level, not inside a subfolder).
2. Import the repo in Vercel. Framework Preset: **Other**. Leave Build Command and Output Directory empty.
3. Deploy.

Data is stored in the browser (localStorage). Chat and leaderboard only work inside claude.ai.
